# Agora
La société fictive 2AW (Art At Work), spécialisée dans la cotation et le commerce d’œuvres d’art, souhaite se doter d’une plateforme de vente aux enchères en ligne, nommée Agora. <br/>
2AW souhaite publier et éprouver son application à grande échelle à l’occasion du salon Art Basel qui se déroulera en juin 2027 (https://www.basel.com/fr/manifestations/art-basel). <br/>
Votre groupe incarne la MOE (Maîtrise d’Œuvre), chargée de concevoir et de réaliser la solution logicielle. L’enseignant incarne l’expert métier représentant la MOA (Maîtrise d’Ouvrage). <br/>
L’objectif est de construire une solution logicielle robuste et évolutive reposant sur une architecture distribuée. La portée du projet est méthodologique, conceptuelle et technique. <br/>
